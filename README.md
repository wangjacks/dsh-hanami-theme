## 📖 前言

当我配置并启动 DeepSeek Harness 后，仔细看了看官方发布的示例视频，发现这个 Harness 的可玩性这么高。我们常说，有时技术力会和作者二次元浓度正相关（当然和本项目无关）。我就想着，要不改一改 Web UI，整一个有点点二次元浓度的主题，于是这个主题就让 DeepSeek 给做出来了。

这是我第一次做这种插件，可能会在安装时有一些小问题，并且暂时还没有做成可持久化应用的形式。当然，您觉得不错的话，可以拿过去改改，优化一下。折腾不息，奋斗不止。

## 🚀 安装到其他设备

> Hanami 是**动态 Cordis 插件**：通过会话内的 `cordis_define` / `cordis_run` 工具安装运行。
> 目标设备只需浏览器能访问 jsDelivr / unpkg（看板娘引擎与模型走 CDN）。

**💡 想先看配色效果？** 用**本地 http 服务**打开本仓库的 `demo.html`（如 VS Code 的 **Live Server**，或 `npx serve .`）——**不要直接双击**（`file://` 会因跨源限制导致脚本不生效），可预览配色。看板娘请在 DSH 内安装主题后查看。

**步骤：**

1. 把 `dsh-hanami-theme/` 整个目录拷贝到目标设备。
2. 打开目标设备的 DSH Web UI，**新建一个会话**，选择 **「创造模式」** 预设。
   > ⚠️ 只有「创造模式」（即 `cordis` 预设）自带 `cordis_define` / `cordis_run` 工具；「标准模式」等其他预设**没有**，装了也无法运行动态插件。
3. 把下面这段指令发给会话中的 agent：

   ```
   请安装 Hanami 二次元主题：
   1) 读取 <路径>/dsh-hanami-theme/theme.client.js 的完整内容
   2) 调用 cordis_define 定义新插件：
      kind: "new"，idPrefix: "hanami"，name: "Hanami · 二次元主题"，
      purpose: "二次元风格主题：6 套配色预设、樱花飘落动画、Live2D 看板娘（多 CDN 回退）"，
      code: { client: <第 1 步读到的完整文件内容> }
   3) 用返回的 pluginId 调用 cordis_run 激活（mode: run）
   4) 首次运行需在 Web UI 批准客户端插件
   ```

4. **记下返回的 pluginId**（形如 `hanam-1`、`hanami-xxx`，以 `hanam` 开头）——后面重新激活会用到。
5. 激活后立即生效：设置 → 通用 里出现「主题预设 / 樱花瓣 / Live2D 看板娘 / 来源与许可」。

**⚠️ 动态插件只活在当前会话进程里：**
- 安装后**别刷新页面、别关会话**，否则主题会消失需重新激活。
- 重启 harness 或重开会话后：在同一会话输入 `@hanam-1`（以你第 4 步记下的 pluginId 为准），或直接把 pluginId 发出来让 agent 执行 `cordis_run` 即可恢复。

**🔧 排障：**

| 现象 | 处理 |
|---|---|
| 没弹出批准提示 | 客户端插件默认需授权；若策略禁用审批，插件可能无法运行 |
| 配色生效但**设置行缺失 / 樱花不飘** | 目标 DSH 版本与本仓库开发版本槽位可能不一致 → 终端执行 `dsh --version`（或 `-V`）查看版本号，反馈给作者 |
| 看板娘空白 / 加载失败 | 看「设置 → 通用 → Live2D 看板娘」行的错误文案；多为 CDN 网络问题，点多 CDN 镜像已自动回退，或点「重试」 |
| `cordis_define` 工具不存在 | 该会话没选「创造模式」预设 → 新建会话时选择「创造模式」（只有它有 cordis 工具） |
